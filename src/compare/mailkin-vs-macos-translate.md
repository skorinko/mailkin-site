<p class="answer">The Translate command built into macOS translates text you select, one piece at a time, in a pop-up. Mailkin translates entire emails automatically when you open them in Mail, in place and with their formatting. Both use Apple's translation; the difference is how much you have to do.</p>

## At a glance

<div class="table">

| | macOS Translate command | Mailkin |
|---|---|---|
| How you use it | Select text, Control-click, Translate | Open the email |
| What's translated | The selection, in a pop-up | The whole email, in place |
| Layout, links, images | Not kept | Kept |
| Subject line | Only if you select it | Translated |
| Remembers choices | No | Per sender, per email, per language |
| Original text | Always shown | One click away (Show Original) |
| Where it runs | On your Mac with downloaded languages | Always on your Mac |
| Languages | Apple's translation languages | Apple's 25 on-device languages |
| Price | Free, built in | 30 emails free, then €14.99 / US$14.99 once |

</div>

## When the Translate command is enough

- You get an email in another language once in a while.
- You only need the gist of a sentence or two.
- You don't want to install anything.

The [step-by-step guide](/guides/translate-email-apple-mail-mac/) shows how to use it.

## When Mailkin is the better choice

- Foreign-language emails are part of your week: a landlord or school abroad, suppliers, customers, colleagues.
- You want to read the whole email naturally, including tables, links and the subject line.
- You want some senders always translated and others never.
- You care that the email never leaves your Mac.
